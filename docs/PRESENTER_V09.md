# 《我的影子迟到了》手持讲稿（v0.9）

主持人用稿。先读普通正文；括号内为操作提醒，不必念出。整场彩排目标为 10–12 分钟，最多 15 分钟。两版真实游玩时长尚未验证，表内没有预设它们必定玩满几分钟。

## 上场前的一张检查卡

- 页面已加载，默认静音；投影能看清上方字幕、当前控制对象与角色脚部。
- 同学使用个人版；教师演示使用剧场版。手机横屏。片名在结尾揭晓，开场不先念作品名。
- 同意展示的参与者优先；默认不记姓名。若录屏、导出或课后分享，另行说明用途并获得同意。
- 总计时器已开启。给回看留约 3 分钟，收尾留约 1 分钟。可用主持控制结束，但须说明并保留操作记录。
- 只选实际发生的节点发问。未发生、跳过或缺少源记录时，直接说明。

## 1. 入场（约 40 秒）

“我们准备了一次很短的互动体验。电脑用方向键或 WASD；手机请横屏，用右侧方向盘。你可以走、停下、改变方向，也可以随时暂停或结束。游戏不计分。”

“参与是自愿的。之后我们想用一位参与者的本局片段一起讨论；展示前会确认同意。不需要说明个人经历，也可以只谈刚才的动作。”

（同学进入个人版。不要介绍门的开法、影子会发生什么、之后该去哪里。遇到操作问题，只说明当前输入方式；让作品先提供行动反馈。）

## 2. 同学个人体验（按实际进度）

（保持安静，让参与者先体验。观察可核对的动作，例如首次去哪、何时停下、控制对象改变后怎样试探。不要一边看一边替对方解释“他在犹豫”“她不听指令”。）

个人版片名出现后：

“这位同学的这一场到这里结束。先保留你记得的一个瞬间，暂时不用给它下结论。”

（若有人未完成，可以继续、暂停或结束。不要称未完成者为拒绝合作。）

## 3. 教师剧场体验（按实际进度）

“接下来邀请一位自愿参与者试玩剧场版。它从庭院开始，第一次玩也可以直接进入。其他人可以留意：这一刻是谁在回应方向输入，另一位又做了什么。”

（确认参与者同意在结束后展示本局回看。开始教师版。不要用讲解提前替参与者解决相遇或接力。）

（如果参与者问当前操作对象，指向上方控制文字和角色脚部标记；可打开“刚才的提示”。提示面板会暂停演出。把操作上的困惑与作品内的发现区分开。）

（若时间紧张，在自然停步处说：“我们在这里收住，保留这一局已经发生的部分。”使用提前落幕，或在说明后使用跳段。回看时确认对应记录，没有发生的事件留空。）

## 4. 四节点回看（预算约 3 分钟）

“接下来先看实际片段，再展开动作与原话。这里记录了输入、位置、控制来源和指引；它不能告诉我们一个人为什么那样做。下面的问题可以回答，也可以跳过。”

### 节点一：第一次试门

（播放本局片段，再点“核对动作与原话”。只读这一局确实出现的事实与指引。）

“这里发生了什么，我们先按记录说：〔读页面中的实际事实〕。当时的指引是：〔若有，读原话〕。对应观察窗口记录的是：〔读回应证据〕。”

对参与者：“你当时先注意到什么？那一步是想试什么？”

课程连接：“这里可以用具身性理解：身体感觉、动作和空间共同参与了经验。按下方向、停住、看到门变化，都发生在同一个处境里。记录能显示动作；刚才有什么感觉，需要由你说明。”

（若节点缺失：“这一局没有这段记录，我们跳过，不补一个失败经历。”若页面为“尚无回应结论”：“这条指引目前没有回应结论。”若页面已记录窗口结束且未回应：“这个窗口没有记录到目标回应，原因未知。”）

### 节点二：影子分离与交接

（先看片段；展开当前帧输入对象、身体驱动与影子驱动。不要把系统自主动作称为玩家操作。）

“这时方向输入交给了〔按记录读〕，另一位的动作来源是〔按记录读〕。你在哪一刻察觉到变化？有没有没察觉的部分？”

课程连接：“审美距离涉及投入行动与保持观看意识。这里从亲自操作到看见另一位行动，给我们一个观察位置变化的机会。是否真的感觉到这种变化，要听参与者的描述，换控本身不能证明。”

（如只有分离、没有交接记录，就只讨论分离。避免问“你为什么放弃身体”这类先替对方规定意图的问题。）

### 节点三：旧动作与主动性

（本局有真实引用时，先看引用现场，再点“查看原片段”，比较源时间。切换后，下方分析与原话仍对应引用现场；源片段当时的台词读画面上方字幕。按需要返回现场。若引用跳过，按页面记录说明；也可讨论本局的身体靠近与影子行动。）

有真实引用时：

“身体引用的是本局〔源起止时间〕的动作。这段过去在新的现场出现，而当前影子仍在回应现在的输入。你认出来了吗？没有认出来也可以直接说。现在的动作与刚才有什么不同？”

没有真实引用时：

“这一局没有可核对的历史引用。我们只看实际发生的相遇：〔读本局事实〕。当身体尝试靠近时，你看到了什么、做了什么？”

课程连接：“这里用反身性审视自己的预设、位置和行动。作为创作者，我们选取了一段旧动作，安排它在新的位置出现；这会影响观众把它理解成重复、示范，还是一次邀请。记录能证明用了哪段动作，不能保证参与者认出或接受了我们的安排。”

（若记录到历史引用因现场相遇而中断，读出绝对源时刻：“引用走到本局〔源时刻〕时，当前影子的实际靠近与移动使身体转为回应现场。”这不说明参与者拒绝了引用。关联事件在当前片段之外时，按页面时间说明。）

### 节点四：外庭回应与离场

（优先播放外庭发起与动作回应。有回应开始事件时，核对源起止时间、重定位和空间缩放比例，并读出完成、身体朝出口离开或空间边界等实际结束原因。无回应事件就不补写；若只有实际离场，只看片段中发生的离场。）

“〔若有外庭发起事件：〕这里先由影子发起行动。〔若有回应：〕它的回应素材来自本局〔源起止时间〕，位置重新安排，动作空间幅度缩放为〔记录比例〕倍。这段经过空间改编，不能据此声称人物在原位置原样复现。你先做了什么？看见它回应后，你又怎样行动？”

“过程中出现的靠近或并行只是临时站位。只有两位实际跨过离场线，才按那一刻的构图记下最后结果：〔读实际结果〕。这段动作有没有让你联想到什么？也可以没有。你愿意怎样描述这个结尾？”

课程连接：“如果讨论投射，联想由当事人说明。我们不从一次靠近、离开或停步推断一个人的性格。可以说这次行动跟随了某条指引，也可以说它去了别处；理由留给当事人。”

## 5. 创作者反思与收尾（约 1–2 分钟）

（点击“查看创作安排”时，明确它是回看新增的说明，不是游戏当时说过的话。）

“我们的一个预设是：给出‘离开庭院’这个目标后，观众会把门当成主要方向。门、踏板、镜头和旁白都在引导注意。参与者可能按这个路线走，也可能观察别处。我们可以核对本局行为，不能把预设路线当成参与者唯一合理的行动。”

“刚才的分析用了〔选择实际讲过的一个概念〕，它帮助我们理解了〔结合参与者原话与本局片段填写〕。它还解释不了〔例如参与者为什么改变方向；如果当事人已说明，换成仍未知的部分〕。这个界限是我们通过这次具体体验多理解的一点。”

“参与者或观众有一处想补充、不同意，或者觉得作品没有表达清楚的地方吗？”

（这是课堂现场提问，可等待一次自愿回应。无人回应时不代答。）

“谢谢。今天保留的是这一次体验与相应的分析。”
