# 课堂使用与讨论

## 一场约 12 分钟的安排

| 时间 | 内容 |
| --- | --- |
| 0:00–0:40 | 自愿参与说明、操作说明与入场二维码 |
| 0:40–3:00 | 同学个人体验，结尾完整揭题，可回看 |
| 3:00–3:20 | 邀请教师开始剧场版 |
| 3:20–6:40 | 教师游玩；同学带着已知机制观看新路线和额外段落 |
| 6:40–10:00 | 四个本局节点，原画面片段＋停帧线索 |
| 10:00–11:10 | 创作者反思自己的任务、误导、旁白预设 |
| 11:10–12:00 | 一次自愿回应；无人回应则自然结束 |

这些是彩排预算，不是系统强制时间；课程上限为 15 分钟。单人成组安排应以教师实际认可为准。

## 回看时怎么讲

- **具身性**：从一段具体输入、停顿和身体旧动作切入。玩家是否认出旧动作，要由当事人描述；程序不能代为判断。
- **审美距离**：从操作者变成旁观者，再看到输入与运动来源。展示这个位置变化，而非先说大家必定会产生某种感受。
- **反身性**：旁白把一段可检测行为解释成什么？创作者怎样设置目标与“正常”路线？使用「旁白，改口」承认解释不等于动机。

界面记录是否进入门口、输入方向、角色轨迹、当前驱动来源。它不能确定玩家在拒绝、紧张、思考或享受控制。

## 真实材料与边界

课堂报告仍需一次实际体验与具体自述。可先请两三位自愿试玩者描述一个记得的瞬间；不要补写他们没有说过的话，也不要把测试脚本当成人类体验。

本局数据只在演示设备内存中。记录或向全班展示他人的游玩前先征得同意，默认不记录姓名，不录摄像头或麦克风。导出的 JSON 可能包含行为轨迹，分享前说明用途并获得当事人许可。不要提交到源码仓库。

## 演示前

1. 打开线上页面并让字体、模型加载完成，测试箭头和手机方向盘。
2. 投影上确认字幕、角色手脚与影子清楚可见；默认静音。
3. 确认切窗口暂停和「继续」；教师版可用演出控制跳段、提前落幕，都会标注。
4. 现场网络不稳定时在演示电脑运行 `npm run preview`，提前完成一次全流程彩排。
5. 准备真实屏幕录制作为额外备用。游戏的状态回看不是录像替代品。

课程依据：用户提供的《艺术＆疗愈》小组报告，强调具体经验、至少一个课堂概念、分析有依据，以及区分观察与推测。该文件未公开上传到本仓库。
