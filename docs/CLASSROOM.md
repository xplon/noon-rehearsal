# 课堂使用与讨论（v0.9）

本作品供一次具体体验与课堂分析使用。整场以 **10–12 分钟**为彩排预算，课程上限为 **15 分钟**。学生和教师的真实游玩时长尚未测定；不要把预算、坐标已知的脚本通关时间或旧版本时长写成新版首玩结果。

主持时可使用 [手持讲稿](PRESENTER_V09.md)。游戏页面展示本局事实、当时原话和开放问题；讲稿负责说明课程概念、创作预设以及现场追问。

## 现场安排

| 环节 | 主持安排 |
| --- | --- |
| 入场与说明 | 约 40 秒。自愿参与、匿名、说明操作；展示参与者记录前先获得同意。 |
| 同学个人体验 | 玩到片名出现。可以暂停或提前结束，不预告踏板解法与控制交换。 |
| 教师剧场体验 | 邀请一位自愿参与者操作剧场版；其他人观察实际动作与当前控制对象。无需先玩学生版。 |
| 四节点回看 | 预算约 3 分钟。每段先播放，再展开“核对动作与原话”；只选有证据的片段讨论。 |
| 创作者反思与自愿回应 | 约 1–2 分钟。说明一个创作预设，邀请当事人补充或不同意。 |

先预留回看与收尾，再用彩排实测决定两次游玩的安排。游玩提前结束就进入下一环节。若探索超出现场余量，可说明后使用主持跳段或提前落幕；回看须保留该操作，不把跳段说成玩家完成。不要用等待或强制绕路补足时长。

## 两版与回看

个人版在片名出现后结束，没有回看。剧场版包含身体与影子的相遇、真实旧动作引用和外侧再次相遇；参与者通过移动做出回应。剧场版的开始也允许首次参与者建立门的规则。

四个节点按本局事件选段：第一次实际试门失败；影子分离与输入交接；旧动作引用或身体与影子的相遇；外庭发起、动作回应与实际离场。每个节点分三层：

1. **本局动作与指引**：实际片段、方向输入、角色驱动、门与踏板状态、当时发出的指引以及有观察窗口的回应证据。
2. **当时出现的原话**：只引用本局记录帧中确实显示过的原文。未显示的排队台词不能当成玩家听到或看到的内容。
3. **留给当事人的问题**：联系一个课堂概念，邀请参与者描述；页面不代替参与者判断感受与动机。

有源时间的旧动作引用可以切换“查看原片段”与“返回引用现场”。原片段的门状态属于过去；引用现场的门由当时真实占板状态决定。片段不足或引用跳过会明确说明，不使用系统示范冒充参与者的旧动作。某节点未发生时显示缺片段，不补演。

指引后的记录可以区分“到达目标”“出现其他行动”或“窗口内未记录到目标回应”。尚未记录回应事件的指引保持“尚无回应结论”，与已结束窗口内未回应分别显示。这些结果只适用于本局的对应窗口。没有输入不等于拒绝；偏离路线不说明玩家具有稳定的性格或某种心理状态。

## 课程概念与证据

| 概念 | 可以从哪里进入 | 需要保留的边界 |
| --- | --- | --- |
| 具身性 | 输入、停步、转身、门的开闭与空间位置共同形成的一次经验 | 身体感觉须由当事人说明；轨迹本身不证明紧张、挫败或舒适。 |
| 审美距离 | 亲自操控与观看另一位行动之间的位置变化；结束后再观看自己的片段 | 参与者是否保持观看意识、是否感到投入变化，不能由换控自动推定。 |
| 反身性 | 审视目标、镜头、默认路线和旁白如何影响观看；创作者说明自己的预设 | 程序能记录动作与触发，不能因此宣称理解了玩家。 |
| 投射 | 参与者自愿说明某个动作让自己联想到什么 | 联想由当事人解释，不替别人解读内心，不诊断或宣称疗愈效果。 |

报告应回答：做了什么；用了哪个课堂概念；概念怎样解释经验、哪些地方解释不了；因此多理解了什么。评分关注概念准确、经验具体、分析有据、表达清楚。技术规模不额外加分，也不需为本作品增设书面作业。

## 真实材料与记录

至少保留一次实际体验及具体自述。可在彩排中邀请两三位自愿试玩者说一个记得的瞬间；原话与观察分别记录，不补写未说过的感受。自动测试、坐标已知的输入脚本和界面截图可以证明相应功能，不能替代真人体验或证明课堂效果。

默认匿名。游戏不采集姓名、摄像头或麦克风；轨迹保存在当前页面，刷新或关闭后清除未导出的记录。展示他人的回看、录屏或分享导出轨迹之前，说明用途并征得同意。导出的游玩记录不提交到源码仓库。

## 演示前检查

1. 提前加载模型与字体。检查电脑方向键、手机横屏右侧方向盘；转为竖屏应暂停并显示转屏提示。
2. 在投影上确认上方字幕、当前控制对象、人物脚部与两侧踏板可辨认。静音下也要完成一次彩排。
3. 检查暂停、切换窗口暂停、继续，以及主持跳段和提前落幕的记录。持续按方向键换控时按屏幕提示松开或换向。
4. 在教师版回看中核对一条真实原话和一段引用的源时间；缺失事件必须显示缺片段。
5. 网络不稳时可使用提前构建好的本地 `npm run preview`。备用录屏应来自获同意的真实游玩，并说明它是录屏；状态回看不是完整屏幕录像。

课程依据：用户提供的《艺术＆疗愈》小组报告要求，经本次工作核对：具体经验或一次小尝试、至少一个课堂概念、观察与推测分开、每组最多 15 分钟。原文件未公开上传到本仓库。这里的课堂预算仍须通过彩排验证。
