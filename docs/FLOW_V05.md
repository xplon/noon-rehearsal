# 当前完整流程（v0.5）

本文件含机制与结尾信息。两种版本共享角色、场景和固定镜头；正式片名只在落幕后出现。

## 个人体验

1. **普通的排练**：门口 → 植物旁 → 前场 → 白圈。输入仍控制身体，影子正常投影；在绕庭院的过程中保存真实方向、停顿、动作和时间。
2. **旧动作继续**：身体回到起点，先看向旧动作的起始方向并转好，再按原时序重演。新输入控制影子，前六秒不解释。影子发现身体离开后，会惊讶、试着跟一步再收住；玩家输入优先接管它。
3. **接应与绕行**：带身体到门口；横穿到左侧；从身体背后绕过去；再一起回门口。每段允许自由走动、停顿和改向。身体先低头注意影子、惊讶、等待、转身，再跟上；急转和重新起步有较短的确认动作。
4. **归还控制**：两者减速会合后恢复身体输入。出口打开，玩家可以离开，也可以继续逗留。
5. **落幕与揭题**：离开时实际穿过门；逗留时影子坐下、路牌转背；长时间无输入则一起坐下。标题“我的影子迟到了”出现，“迟到”晚到并赶上。个人版只提供再玩，不提供回看。

## 教师演出

普通排练与旧动作之后，追随段依次包含：门口接应、横穿、身体休息、从身后绕行、圈内谢幕、自由返场。随后影子倒序走过领路末尾八秒与实际减速会合尾段，身体跟随；再归还控制、落幕、揭题。

- 休息：身体先站稳，再坐下、起身；影子仍由玩家控制。
- 谢幕：影子进入中圈提出谢幕，身体走到圈内站稳才鞠躬。始终不进入时，演员会表示迟疑并继续下一段。
- 返场：给玩家一段可改变方向的实际领路时间，再使用真实路线逆序引领。倒走调整速度而不伪称逐帧倒放骨骼；没有运动就如实停留。
- 四个回看节点来自本局的到达事件、旧动作播放开始、倒序引领、真实旁白。可显示输入和动作来源，并让“旁白，改口”承认它不知道玩家的动机。

## 时长与不配合

固定 60 Hz 模拟、无主持跳段的当前结果：

| 输入策略 | 个人版 | 教师版 |
| --- | --- | --- |
| 快速追随当前提示圈 | 122.55 秒 | 181.75 秒 |
| 全程无输入 | 161.47 秒 | 216.13 秒 |
| 连续改变方向，不主动配合目标 | 182.90 秒 | 242.82 秒 |

这些是工程策略的结果，不是参与者平均值。开场和各段有表演窗口，玩家在窗口内始终可以操作；完成目标后的反应、环顾和重新尝试也占据时间。窗口上限保证不因拒绝提示而卡住，实际转身、减速与会合不跳帧、不传送，因此总时间会随路线变化。教师版回看不计入表中。

课堂建议仍按约 12 分钟准备，并给自由探索和讨论保留余量；不靠全程不动的测试来证明体验丰富，也不把计时达标当作艺术质量验收。
