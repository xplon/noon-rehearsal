# 原创角色资产

角色是一名奶油白短斗篷演员，带珊瑚围巾、软鞋与简洁面部。几何、骨架、蒙皮和动作全部由本项目的 Blender 脚本制作，无外部角色或动作素材。

## 文件

- 游戏资产：`public/assets/actor.glb`
- 机器可读参数：`public/assets/actor-manifest.json`
- 可编辑源文件：`assets-src/noon-actor.blend`
- 完整生成脚本：`scripts/build_character.py`
- 造型与动作检查图：`assets-src/previews/`（前、侧、后、四分之三视角，以及走路、坐下、鞠躬、摊手）

源模型为 Blender Z-up、-Y 朝前；GLB 已转换为 Y-up、+Z 朝前。脚底在地面附近，站立总高约 1.745 米。角色整体根节点没有水平位移或转向动画，移动和朝向由游戏逻辑决定。

模型有 22 根骨骼，源网格 6,468 顶点、12,252 个三角面；导出的 GLB 约 0.51 MB。GLTFLoader 会将多材质网格呈现为多个共享骨架的 SkinnedMesh primitive，不应假设只有一个渲染 mesh。可通过 SkeletonUtils.clone 克隆整个场景根节点来建立影子演员。

模型包含实际蒙皮：身体网格在 hips/spine/chest 间混合；围巾有两节骨骼；其余服装、手脚与面部按对应骨骼绑定。动画包括根节点、骨骼的旋转、位移与眼睛缩放，可以由最终骨架矩阵记录器完整采样。

## 动作

| 名称 | 时长 | 用法 |
| --- | ---: | --- |
| `idle` | 3.2 s | 循环呼吸、轻微头部姿态和眨眼 |
| `walk` | 0.8 s | 循环原地步态；速度应由游戏按实际位移匹配 |
| `chase` | 0.6 s | 前倾、较大步幅的追赶循环 |
| `look` | 2.4 s | 低头看地面并轻微侧倾 |
| `shrug` | 2.2 s | 一次摊手，起止为中性姿态 |
| `sit` | 3.2 s | 已坐下的保持循环，可从站立交叉淡入；不是完整坐下/起身过渡片段 |
| `bow` | 2.5 s | 一次完整鞠躬，起止为中性姿态 |
| `turn` | 1.8 s | 头部与上身回望，角色根节点不旋转 |

`sit` 把 hips 降低 0.455 米，角色根节点仍应放在地面。不要另把角色 root 再降低同样距离，否则会陷地。需要正式的坐下/起身节奏时，可在这些姿态之间用受控短过渡，并记录过渡后的骨骼状态。

动作本身不决定场景的当前输入归属、目标判定或旁白。动画混合结果需由游戏记录，回看不重新运行表演分支。

## 材质与渲染

实际使用材质名：`Cream`、`CreamShade`、`Skin`、`Coral`、`Ink`、`Stitch`。GLB 保存基础平色，网页渲染器可以在保留颜色的前提下替换为 toon 材质。没有图片纹理、外部贴图或可泄露故事信息的贴图标签。

影子建议克隆骨架与网格，在蒙皮变形之后投影顶点；保持与主体相同的动画姿态来源。不要用屏幕上的一张静态椭圆代替这套 silhouette。

检查图使用 Blender 的普通灯光展示造型，**不代表网页最终 3 渲 2 的线条与色阶**；最终画面仍需在浏览器中检查。

## 重建

已用官方 Blender 4.5.15 LTS macOS arm64 实际生成和渲染。命令：

```sh
blender --background --python scripts/build_character.py
```

脚本会从空场景重建资产、导出 GLB、保存源文件，再生成八张检查图。演示用灯光、地板和摄像机不会进入游戏用 GLB，也不会进入保存的资产源文件。

本次通过官方 DMG 的只读挂载使用 Blender，没有替换用户应用。临时执行路径为 `/tmp/noon-rehearsal-tools/mount/Blender.app/Contents/MacOS/Blender`，仅在该镜像仍挂载时可用。
