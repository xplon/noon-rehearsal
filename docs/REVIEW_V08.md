# v0.8 评估回应与修订

2026-11-06。依据用户指定的网页评估、独立源码审查、主代理浏览器操作及受限截图盲审修订。网页评估建议从反复离场和总人数名额，收敛为有固定规则的留门接力；保留真实动作、控制交换、追随与四节点回看。

## 本轮完成

| 问题 | 当前行为与证据 |
| --- | --- |
| 门与建筑、碰撞不一致 | 门洞、侧铰链、门叶扫掠、踏板、导航与过门判定共用 `space.ts`。高拱入口保留屋面与塔楼，门外浅色落脚区可透过拱洞辨认。 |
| 门靠近即自动打开、半关时卡住 | 踏板才产生开启需求；通道占用只阻止关闭。按实际开度绕行，提前离开内踏板仍可恢复。 |
| 一人名额让玩家无从推断解法 | 删除总人数名额。任意内外踏板占用都留门；先过者到外侧接手，后过者通过后在外踏板会合。 |
| 控制对象和任务不清 | 持续显示当前输入对象、目标和情境选项。最初六秒保留发现窗口。提示回顾自动暂停，暂停仍能看清舞台。 |
| 两个白圈提示混淆 | 开场只要求门前圈；返回时再点明庭院中间刚亮起的圈。目标圈加粗，与填充色踏板区分。 |
| 旁白滞后、结尾泛化 | 接手时清除过时排队提示；台词描述已发生动作，当前行动单独显示。结尾分别回扣谁先留门、谁后来接出搭档。 |
| 多次收尾及教师强制重演 | 只保留一次落幕。教师在最终接力前可接受、跳过或中断真实路径重排；个人版无该段、无回看。 |
| 记录与回看夸大行为 | 区分主动选择、未回答、系统协助、未完成、主持跳段；不推断心理。第三卡覆盖真实选择与接手/落幕；回看原话来自已显示的帧。 |

## 独立复核发现与修复

源码审查通过反例找到：未踩踏板就开门、半开门死锁、继续尝试立即再次超时、移动片段起步速度突变、短片段末帧冻结、系统示范误称玩家动作、重排播放前取消仍记开始、晚点留下的回看片段错位，以及回看夸大离板与接手的先后关系。以上均已修复。身体旧路线首尾平滑起停，中段保留真实路径、时序与停顿，记录和说明明确这一处理。

独立首玩代理没有可用浏览器连接，因此只看指定截图，未读源码或设计文档。它认为控制对象与选项基本清楚，但两个目标圈、门内外位置、结尾反馈仍有歧义。随后完成上述圈位提示、浅色后廊、会合位置和分支结尾调整。**这是受限截图盲审，不是真人首玩或独立完整游玩。** 动作流畅、艺术感与真实课堂趣味不能由这些截图证明。

## 验证范围

- 自动检查覆盖运动/转向、投影与骨骼重建、碰撞、两版两种先后、退回重试、未回应、明确留下、教师接受/拒绝/中断、真实记录与回看。最终测试清单以仓库 `npm test` 与发布工作流为准。
- 主代理实际用方向键完成个人版共同离场，结尾仅再玩；教师版完成接受重排、系统接应、继续尝试、改成影子先过、共同离场、四节点回看、来源线索、旁白解释与 gzip 导出，无主持跳段。
- 教师检查局记录 **216.30 秒、6,506 帧**，真实重排路径长 **9.7465** 场景单位。过程中有工具检查造成的未操作，触发了一次预算继续；此数值**不能当作正常玩家时长或内容量证据**。
- 浏览器完整局之后最后调整了外侧会合点、浅色后廊与少量文字；这些变更由最终引擎回归及定点渲染复核，未把旧局说成最终构建的完整首玩。
- 1280×720 桌面、844×390 横屏提示/暂停、390×844 转屏提示检查。横屏检查是浏览器视口，不是实体手机性能测试。两种先后各三个定点帧检查门外身体与长影子；这些是标明的脚本状态画面。
