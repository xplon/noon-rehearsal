# v0.9 实现复审与试玩记录

2026-11-09。本文件区分源码验证、独立模型试玩、开发者复测与尚未验证的真人体验。最终流程见 [FLOW_V09.md](FLOW_V09.md)，包括两版 Mermaid 图；讲述安排见 [PRESENTER_V09.md](PRESENTER_V09.md)。

## 本轮实现

- 同一座双庭院：连续隔墙、可见门洞、侧滑门与门袋、两侧踏板和外庭离场通道。门叶模型、碰撞、导航与地面投影使用共同空间参数。
- 所有剧情抉择改为走、停、靠近、走开、留板、撤脚或回头。入场、暂停、提示、主持控制和回看仍有界面按钮，不承担剧情分支。
- 个人版完成一次试门、影子分离、两次换控、留门接力与共同离场，完整揭题，无回看。
- 教师版独立从开场体验开始，增加尝试恢复重合、引用本局真实动作、外庭动作回应与可改变的同行构图。当前行动能打断引用，后来的留板位置能改变先过门者；回内庭会让搭档重新留门。
- 回看显示实际动作、输入对象、指引、显示过的台词和开放问题。手持讲稿承担课程概念、创作者反思与讨论组织。

## 独立评估的方法与边界

前期匿名文字 A/B 比较与教师方案讨论见 [REVIEW_V09_DESIGN.md](REVIEW_V09_DESIGN.md)。参考会话的 Pro 评估已读取：采纳固定门规则、真实来源对照、可打断的历史引用、外庭独立发起以及页面事实／讲稿概念的分工。课程要求以用户提供的《艺术疗愈_小组报告.pdf》原文核对；没有把技术复杂程度作为报告质量的替代指标。

实现后，两位新上下文代理分别完成个人版与教师版。未给它们源码、设计稿、用户批评或另一份报告。由于代理浏览器连接不可用，采用**截图中介的独立决策试玩**：开发者按代理要求输入、发送当前画面，后段还按代理选定的可见目的地辅助执行方向。暂停用于传递截图与判断。两位均自然结束，没有主持跳段；教师代理完成四节点回看及源片段对照。

这属于独立模型评估，不是人类盲测，也不是两位代理各自连续操纵浏览器的实验。运动执行辅助、暂停、静态截图与工具延迟均会影响发现和时长。完整报告和实际记录保存在本地 `artifacts/v09-qa/`，没有将游玩记录上传到网站。

## 独立首玩发现及处理

| 观察 | 本轮处理／仍需验证 |
| --- | --- |
| 个人版代理能复述“自己开门失败—影子成为搭档—内外留门—一起走”，认为“过来”之后影子实际过门最有满足感 | 保留这条因果主线。个人版完整落幕；不加入按钮解答 |
| 门板亮起、门开、离板门关让两位代理掌握规则 | 保留同一物理规则；扩大外庭，封闭视觉上似乎能绕过的边路 |
| 影子的脚点不易定位，换控主要依赖顶部文字 | 提高当前控制者脚部细圈的尺寸与反差；交接先停步、相互看，再接受新方向。实体手机辨认仍待测 |
| 教师代理被“门还没准备好”引向等待 | 改成“人到了。门倒是纹丝不动。”，只评论已发生的事实 |
| 首玩未认出身体在引用旧动作，感觉中段要等待；回看后才辨认 | 从最早偶然擦板改为最近一次试门的连续片段，最长四秒；不压缩片段内停顿。缺少合适素材则明确跳过。修复后的可识别性尚未经过另一位新人验证 |
| “这次，跟紧”让代理跟走、门再次关闭 | 保留为身体尝试旧办法的台词，后续动作承认尝试失败；它不是旁白的标准答案。此处的戏剧性与困惑程度仍需连续真人试玩 |
| 外庭模仿被理解成简单追随 | 改成影子自己的短句“你那几步，我学会了。”，回看保留真实源时间与空间改编说明。当前身体继续可控，可直接离场略过 |
| 前两个回看片段重复；关联的先前指引消失 | 按最近一次实际试门／分离与交接分段，最多一秒重叠；片外关联指令、回应与未结窗口分别标明 |
| 浏览器复测发现沿墙斜向移动容易整段制动；短交接截断台词 | 改为优先限制朝墙法向速度、保留沿墙分量；原射线安全制动继续作为后备。相同戏剧动作中的换控转场保留未读完的台词 |

两位独立代理都认为接力和换控有发现感。教师代理明确指出旧动作的首玩辨认没有成功。回看让它理解更多，不能据此改写之前的体验，也不能据此宣称课堂学习效果已验证。

## 修订后的实际浏览器复测

开发者已知机制，使用普通方向输入与方向盘，未注入游戏状态或使用主持跳段：

- 教师版：走开回应身体邀请 → 最近一次试门动作引用 → 影子留内板、身体先过 → 外板接力 → 外庭实际动作回应 → 靠近后继续移动 → 实际越过离场线 → 题名。完整查看四节点、原片段、外庭／结尾片段，导出本局 gzip 记录。
- 个人版：844×390 的真实游戏 iframe 内从入场走到共同离场与题名。实际使用方向盘，门洞定位时也使用键盘。结束只有“再走一遍”，无回看。390×844 显示横屏提示；返回横屏保留暂停与本局状态。
- 教师直接页面控制台未记录错误／警告。响应式 iframe 测试工具曾报告一次无源地址的 `MutationObserver` 非 Node 错误；游戏完成、转屏和继续均正常。该单条日志无法可靠归因，不把它计作“所有环境零错误”。

截图与导出仅是开发验证材料，不能证明实体手机帧率、投影可读性或真人趣味。

## 时间结论

| 测量方式 | 个人版 | 教师版 | 能支持什么 |
| --- | ---: | ---: | --- |
| 知道坐标的快速策略 | 28.93 秒 | 45.28–61.07 秒 | 可达性与最短节奏边界；不能作为首玩时间 |
| 独立模型截图中介首玩 | 未导出精确游戏时钟 | 124.43 秒，37 次暂停 | 这次中介运行的时间；暂停不计入游戏时钟 |
| 修订后开发者完整复测 | 完整结束，未导出精确时钟 | 125.35 秒，22 次暂停 | 功能复测；含定位、分段观察和无输入时间 |

独立教师局：有输入 60.93 秒、角色自主阶段 12.40 秒、可控但无输入 51.10 秒。最终开发者教师局：有输入 44.70 秒、自主阶段 12.18 秒、可控无输入 68.47 秒。角色运动时间与这些分类重叠，不能相加。无输入也不代表舞台没有动作。

**目前不能声称个人版稳定提供两分钟有效内容，或教师版自然首玩必定达到三分钟。** 两版都不设最低计时、强制绕圈或超时自动选结局。个人版按用户指定的协作短剧收束；教师版增加了可观察的独立事件，但是否足以持续吸引观众仍需真人连续试玩。

课堂整体以 10–12 分钟作为彩排预算、最多 15 分钟，游戏提前结束就进入实际片段讨论，不用游戏等待补时。下一轮真人验证应记录自然完成时间、首次辨认换控／引用的时刻、主动探索与操作受阻的差别，再决定是否增加新的互动。
