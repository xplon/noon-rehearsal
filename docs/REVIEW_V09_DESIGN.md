## 当前问题核查

| 问题 | 当前证据 | 结论 |
| --- | --- | --- |
| 按钮泄露后续解法 | `Game.actions()` 同时提供“身体先过，影子留门”“影子先过，身体留门”“我们留在这里”；`guidance()` 直接解释内外踏板接力 | 用户的批评成立；菜单抢在动作之前解释了谜面和方案 |
| 门的位置与叙事空间不符 | 当前截图中门嵌于后廊，旁边为视觉开放拱洞；`space.ts` 将其他后部区域阻断，外侧仅有窄通道和小落脚处 | 视觉可通行性与碰撞区域不一致，难以承载互相留门的表演 |
| 旁白偏教程 | 当前开场目标是门前白圈，再回白圈；后续目标直接说明控制对象、去向与接手动作 | 主线清楚但发现被提前解释，需要环境和角色承担更多信息 |
| 新隔墙可能暴露投影穿透 | 影子顶点投向固定地面；逻辑碰撞只限制 root | 新布局必须同时解决投影遮挡，单改门坐标不够 |
| 两分钟内容是否成立 | v0.8 文档明确快答个人约 56–60 秒；本轮代理对新学生提案估计约 60–105 秒有效内容 | 不能由“方案更好”推导时长达标；需另测新版本首玩 |

## 匿名 A/B 比较结论

代理认为 B 的因果更集中，A 对操作规则的交代更完整。B 不能直接照抄为定稿，其主要风险是：**玩家走到触发点，角色替玩家完成真正的发现。**

| 项目 | A：当前流程 | B：用户新提案 |
| --- | --- | --- |
| 主线 | 返回、回放、换控、选择、接力，阶段间必要性较弱 | 想离开、开门失败、发现合作，因果连贯 |
| 发现感 | 说明可靠，但菜单与教程提前揭示方案 | 第一次失败有效；后续需防止自动解决 |
| 操作可信性 | 控制对象较明确 | “自然交还”尚需具体规则、反馈和恢复方式 |
| 主体性 | 有选择，但按钮替玩家定义立场 | 动作可以表达差异，过多自主演出会削弱参与 |
| 课程表达 | 旧动作成为当前身体，独特性较强 | 谁行动、谁观看、谁替谁维持条件更集中 |

已采纳：影子自主段不去踏板；真实开关门触发分离；三次交接明确定义；可逆撤脚、回身、靠近/退开产生当前动作变化。保留 A 的真实身体引用，但只在教师版出现。

未采纳：为了完整保留所有分支而继续使用文字选择；把静止算作留下；用自动成功掩盖玩家没有发现机制。

## 教师版迭代

曾考虑身体引用“离板至撞门失败”片段，影子实时开门。独立评审指出：门已打开而身体继续旧停步/后退，很容易被看成 AI 没更新判断。

最终改为引用“第一次上板开门前的一段真实连续行走”，结束在内板。身体抬头恢复现场角色，主动留门；玩家控制影子先过，到外板后再接手身体。

复审结论：这版因果更自洽，二周目差异真实发生在先行者和等待者的交换中。历史片段只驱动身体，门必须实时计算；引用结束的现场站位不能伪装成历史。引用短、缺少特征时，自我辨识效果可能较弱，回看应明确实际来源。

独立估计：短引用本身新增约 10–25 秒；不能宣传为新增 45–90 秒。没有强制按满时长的设计。

最终稿一致性复核另指出三处缺口，均已补入设计：引用终点须取身体确实仍占板的真实记录帧，不能取可能已离板的开门动画结束；跳过引用时身体以现场动作留板，不能等待一个永不发生的“引用完成”；正常持续前进时，通过先行者可见的回望慢走和搭档实际追上完成匹配，不能等玩家偶然松手或在镜头外瞬移。这些是设计修订，尚待运行验证。

## 空间与交接审核

- 固定摄影机下，静态短墙不能实现“身体跨门后玩家才看见被完全挡住的外板”。改为初始局部可见，或者由真实门运动解除遮挡。
- 连续隔墙两端连接实体边界，关门时导航区域断开；开放拱洞不能再用隐形墙封住。
- 主庭院与外庭均有完整表演地面。门宽、转身净深、内板距离需结合实际移动速度校验。
- 滑门替换铰链门后，旧扫掠区防夹逻辑必须同时删除，防止提前冻结门形成单人冲门漏洞。
- 影子根坐标、脚部控制反馈和踏板判定一致。长影轮廓跨墙须裁剪，不能把长影整体当作巨大的碰撞物。
- 取消开场故意偏航。影子接手时方向权立即属于玩家，只平滑速度/姿态，不持续混合两条相反路线。
- 影子试板时，身体停在板外观察；否则同时占板会破坏因果可读性。
