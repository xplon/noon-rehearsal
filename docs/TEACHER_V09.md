# v0.9 教师版：同一庭院里的独立完整剧情

2026-11-09。**实施规格；尚非实机体验或时长验证结果。** 用户已选择在同一双庭院空间中扩展完整教师剧情。本文只规定教师扩展，学生主线及共同门规则见 `FLOW_V09_DESIGN.md`。两稿冲突时，教师扩展以本文为准。

教师首次进入也必须亲历“想离开—自己开门又关门—影子独立”。不假定教师已玩学生版。新增三场依次改变身体和影子的关系：身体试着把影子收回脚下；过去的动作成为当前可利用的开门机会；门外影子选择自己的站位，双方通过实际行动重合或并行离场。

只使用当前角色、骨骼动画、目光、连续运动和现有踏板门。没有第二道锁、通行次数、收集物、强制绕圈或新增大资产。教师的快通关仍可明显少于 2.5 分钟；不得靠隐藏等待补足目标。

## 共同前段：首次玩家知道自己要做什么

1. 开场：“午休结束了。请从庭院出去。”输入可靠地控制身体。
2. 内板、外板、滑门及实体边界从开场存在。玩家实际踩内板开门，离板后门按同一物理规则关闭。
3. 只有首次开过门、离板、门实际关闭，且身体到达关门前，才进入异常。尚未尝试踩板，不能因接近门就演分离。
4. 身体抬手后收回，影子的手延后收回；影子移开，身体先看后追。无直接控制约 3–5 秒，影子不去踩板、不展示解法。
5. 回头动作完成，同帧将方向输入与脚部标记交给影子。下一场从当前双方真实位置开始。旧方向需松开或改变后再送给新对象，持续按住时显示简短交接提示；不令新角色突然冲走。

门始终由实时占板和门洞防夹驱动。独立影子用脚部锚点占板；附着投影不算第二位。剧情阶段、历史门状态和旁白均不能直接改变门开度。

## 第一场：身体想把影子“穿回去”

### 可见动作与触发

影子刚交给玩家时，身体低头看自己的脚，再看影子，向影子所在位置走去。动作表达“把原来属于脚下的东西找回来”，不靠大段说明。

- `restore-start` 捕获此刻影子锚点为 `restoreTarget`。身体只走向这个实际看见的位置，不无限追逐每一帧的新位置。
- 玩家始终控制影子，可接近身体、留在原处、向远处走或直奔踏板。身体输入来源为现场角色行动，不是历史记录。
- 身体到达 `restoreTarget` 后查看当前影子位置。身体从开始接近到停稳构成一次完整尝试，不要求玩家躲开若干次。
- 若影子仍与身体接近，身体低头确认，面向门试走约 0.9–1.2 米。影子继续接受当前输入，**不因接近自动附着**。
- 若影子已经移开，身体在原位置停下，转头找到现在的影子，做一次短 `reach` 后收回。身体不再追第二轮，转向门。
- 若双方试走仍靠近，身体看一眼影子，继续转向门；不宣称控制已经恢复。若试走分开，身体先看空出的脚下，再看影子，接受它仍独立的事实。

近距初值 `distance <= 0.45`；远距/明显分开初值 `distance >= 0.75`。阈值需按当前模型尺度验证，使用滞回避免边界抖动。它们只选反应，不是通关条件。

### 真正影响后续的分支

| 本场实际事实 | 本场反应 | 门边后续反应 |
| --- | --- | --- |
| 身体接近时，玩家曾主动向它移动，双方接近 | 身体低头确认，再试走 | 后续邀请采用短伸手和目光交流 |
| 影子在身体接近期间移动到更远处 | 身体走到刚才的位置，发现位置已经变了，转头定位 | 门边先寻找影子方位，再发出邀请，不重复伸手扑空 |
| 影子无输入，身体自行接近 | 同样按实时距离作动作；记录接近由身体造成 | 使用中性看向对方的邀请，不能说“你回来了”或“你答应了” |
| 双方短暂同向同速 | 身体继续走，暂时看似恢复旧关系 | 后来一位留板另一位离开时，才看见它们仍能各自行动 |

这些是行动记忆，不是亲密、顺从、信任或拒绝分数。后续只改变可见的目光、手势和一句事实回应。

### 旁白

仅当身体真的接近影子、准备试走时，可说：“好，站回脚下，应该就好了。”若随后实际分开，再说：“……这句说早了。”若两者仍同向，第二句不播放。旁白的判断允许落空；事件记录不得把判断当成事实。

没有输入也能结束这次身体自己的尝试，但不能据此选结局。此场没有新的无控制观看段。

## 第二场：过去的一步，当前的机会

### 选取真实记录

共同前段记录首次有效上板 `firstInnerEnter`、首次离板 `firstInnerRelease` 和首次到达关门前 `firstClosedGateArrival`。原始记录保留时间、身体位置/朝向/姿态、输入、占板者和门开度。

优先选取从首次上板前约 0.6–1.2 秒到首次离板后一帧的连续源段；终点最多在离板后约 0.15 秒，且必须早于任何旧撞门/关门前停步动作。目标源段 3–6 秒，上限初值 8 秒，短记录照原长度播放。

首次在板上停留可能很长。若完整段超过上限，改选**首次离板之前至离板后一帧的连续尾段**，允许源段从板内开始。保存 `quoteSourceSelection = 'continuous-tail-long-dwell'` 和省略的源区间；回看明确“所引片段开始时身体已经在板内”。不得压缩中间静止，不得把尾段称作完整的首次上板过程。优先完整段记为 `complete-first-press-release`。

身体先以现场运动走到真实源段起点，再对齐真实起始朝向和姿态。准备段不冒充历史。玩家一直控制影子；身体准备走到源起点不需要玩家等在固定位置。

若源段不足、历史源点不可达，或合法场景变化使精确路线不再可播放，记录跳过原因，身体恢复现场接应。不生成替代历史，也不把当前动作写成过去。准备路线过长时可缩短为更近的真实尾段，并记录 `continuous-tail-shorter-return`；仍不合适则跳过。

### 引用时的双重现场

身体：“刚才这一步，我再走一次。”身体精确复演源段；当前影子仍由玩家操控。可见状态只简短标注“身体 · 刚才的动作”，不先讲先后通行解法。真实引用与恢复现场在脚部来源标记、记录和回看上清楚区分。

历史只驱动身体。门、踏板、防夹和影子都使用当前世界状态。源段结束于首次离板，不把旧撞门接在后面，因此不会出现门已打开、身体仍持续对着空门做撞门动作的误读。

玩家可以借这次开门直接通过，也可以在门口观察、抢先踩内板、离板或折返。没有“错过就重演一次”的要求。引用最多执行一次；完成或跳过后，身体恢复对现场的响应。

门已由当前影子打开时，过去的身体仍照真实路线走完这段上板/离板；它没有在历史身份中判断当前门。引用结束后必须先看当前门和影子，才开始下一项现场行动。

### 引用结束后的唯一分流

按下表从上到下判断，均须使用实际位置与稳定占板状态。`isOutside` 必须表示完整通过门平面，不可拿脚部擦过门线当作通过。

| 当前事实 | 身体的现场行动 | 玩家继续控制 | 后续交接 |
| --- | --- | --- | --- |
| 影子已在外侧且已稳占外板 | 身体确认当前门；准备自己过门 | 将控制交给身体 | 身体实际过门后进入外庭场面 |
| 影子已在外侧，但尚未稳占外板 | 身体回到内板、留门，看向影子 | 影子 | 影子稳占外板后交给身体；身体自己走出来 |
| 影子在内侧且稳占内板 | 身体看门、看影子，走向门：“那我先。” | 影子 | 身体通过后观察同类外板，主动走上并留门；玩家影子随后过门，双方外侧后才交给身体 |
| 影子仍在内侧、未稳占内板，或正处门洞安全带 | 身体回内板留门，给影子当前机会 | 影子 | 走影子先过的接力路径 |

身体主动走上外板属于此刻角色看懂环境后的行动，记录为 `partner` / `hold-door`，不是用户操作，也不叫作历史复演。它只在玩家已经用内板留住门、身体确实走到外侧之后发生。

分流后允许一次物理交接完成，不把玩家后续绕回当成重选菜单：

- 身体已从内板走向门时，玩家影子撤脚，门按实况关闭；身体在内侧安全位置停下。影子重新占板，身体继续。角色不会无提示改成另一条完整接力剧情。
- 身体仍在内侧且影子离开内板去到门外，当前门若合法保持通行，可在安全停稳点改为影子先过；记录 `relay-order-changed-by-action`。不得在门洞中抢换输入对象。
- 外板已由身体稳定占据时，玩家影子可继续探索或返回内板；身体不提前离板、不替玩家移动影子。
- 玩家影子已在外板、身体引用尚未结束时，保留当前输入。源段一结束且条件仍成立就交接，不补额外站立计时。
- 引用期间影子进入门洞，防夹只作用于真实门洞；不能用剧情阶段保留整扇门的通行权限。
- 两位都未占板、门已关闭时，当前身体可回内板留门；这是现场接应，不重播源段。

稳定占板初值约 0.20–0.30 秒，仅用于避免边缘抖动和误换控。踩住门立即响应，不能等稳定计时结束才开门。

### 旁白与未操作

影子真的借历史开门过到外侧时，可说：“还是刚才那一步，这回多过去了一位。”影子在内板使身体先过时，可说：“我刚才把先后想早了。”两句互斥，也不能在行动发生前播放。

引用准备和引用中，玩家始终能移动影子。无输入只会让身体完成这次有界行动并留下接应，不会使两位自动过门或自动落幕。等待期间先靠门、脚部标记和角色视线提供状态；确实长期无进展时只提示当前事实，例如“门开着，还有一位在里面”。主持跳段和显式辅助仍可用，须单独记录，不能被分析为玩家选择。

## 第三场：门外，影子站到自己的位置

### 空间与启动

两位必须都实际到达外侧，最后留板者才离板。身体恢复当前输入；影子独立行动，不自动吸回身体脚下。

外庭保留一条可见的离场方向。选一个偏离这条直线、仍可见且可走的侧方位置 `shadowOwnSpot`：初值在门外接力区向出口前进约 0.8–1.2 米，再侧移约 1.0–1.5 米。它不是按钮、踏板、新目标圈或隐形锁。

影子先看身体，再看这个位置，自己走过去，转身看身体。可以用现有 `look`、`walk`、`turn` 表达。身体全程可控，玩家无须等影子到点。双方初始位置、碰撞和退出路线变化时，侧方位置从可行区域计算，不能固定到墙后。

若门前第一场有玩家主动接近身体的记录，影子在侧方用一次短 `reach` 回应；若此前主要发生远离，影子先清楚转身确认身体的位置。没有相关输入则仅用中性目光。这种差异不改变路线长度或成功难度。

### 靠近同向：重新匹配

玩家身体可走向影子。影子看到身体靠近后，从侧方真实走近身体、调整方向；只移动影子，不替玩家修正身体的方向输入。

重新匹配需同时满足：

1. 外庭交接后出现过有效的当前身体输入，并确实造成了朝向影子的接近；不能仅因影子自己走到静止身体附近就选重合。
2. 双方脚部位置、速度与朝向接近。原型阈值可从距离 0.35 米、速度差 0.45 米/秒、朝向差 0.35 弧度开始，连续满足约 0.18 秒。
3. 前述条件发生在实际外庭地面；双方没有隔墙、门洞或其他障碍。

达成后从当前姿态逐渐恢复附着，保存 `outside-match`。这只是当前角色形态改变，玩家还需向可见出口移动；不能一靠近就强制播放整段走出场。持续按住的方向保持可靠，影子真实追到与身体相符后才附着，不允许位置跳变。

若双方接近后玩家再次转开，影子停止匹配，转为跟随/并行；未达到全部条件就不能报告“已经重合”。

### 持续离开：并行同行

玩家身体也可以沿出口方向继续走。用真实向外位移触发：身体从外庭接力结束位置沿出口轴前进约 1.2–1.6 米，且此段发生过有效输入，并尚未匹配。这里记录 `parallel-invitation`，不是不可撤回的结局选择。

影子离开侧方位置，沿身体侧后方的可行路线赶上，成为并行搭档。玩家若这时回身靠近，仍可真实匹配。只有最终两位实际跨过可见离场线时，才按最后事实记录 `joined-exit` 或 `parallel-exit`。

不能在外庭出口前设置隐形墙等影子，也不能为了同步暗中降低玩家身体速度。必须按现有速度和侧方距离验证持续按住前进时影子能否在镜头内到达离场区域；若来不及，缩短影子的侧移、提前开始跟随或延长可见外庭纵深。还可接受身体先进入离场通道、影子随后实际进入；镜头继续容纳两位，不瞬移补齐。

如果玩家身体在影子仍选择侧方位置时已经朝出口走，上述位移触发立即生效，影子从当前位置转为跟随，不强制先走完侧方路线。

影子尚未赶到时，不能直接宣布“到齐”。两位最终均已通过真实离场线后才开始落幕驱动，片名揭晓，“迟到”两个字随后到达。

### 无输入与旁白

无输入时，影子到侧方停下、看身体，不自行选择并行/重合、不替身体走向出口、不自动以“留下”结尾。当前输入对象保持身体，暂停、帮助、主持控制仍可用。

影子自主走向侧方前，旁白可轻率地说：“现在总该跟回去了。”影子真的停在另一个位置后，才接：“好，这句收回。”玩家身体已主动继续离开、影子因此提前转为跟随时，删除过时的第二句。字幕不构成等待条件。

## 状态与事件最小接口

建议以现有状态机中的 `beatPhase` 表达教师细分，不要求为了本稿整体重写引擎：

```text
共同首次开关门 → 分离与交接
→ restore-approach → restore-test 或 restore-look-away
→ quote-prepare → quote-playing 或 quote-skipped
→ relay-shadow-first 或 relay-body-first
→ outside-own-position → outside-accompany / outside-matching
→ 双方实际离场 → curtain → 四节点回看
```

关键事件至少记录：

| 事件 | 必要字段 |
| --- | --- |
| `restore-start` / `restore-result` | 双方位置、固定尝试目标、实时输入是否出现、接近/远离的实际来源、结果 |
| `quote-source-selected` | 原始起止时间、首次上/离板时间、`quoteSourceSelection`、完整/尾段覆盖范围、缺失/跳过原因 |
| `quote-start` / `quote-end` | 当前开始/结束时刻、原始时间游标、完成/中断/跳过、当时双方位置和占板者 |
| `relay-order-by-action` | 分流事实、谁先过、何时确认完全在外侧、门开度、当前控制对象 |
| `control-handoff` | 前后对象、触发事实、输入交接等待是否启用、双方实时位置 |
| `outside-own-position` | 选点、实际路线、是否被当前玩家离场动作提前转为跟随 |
| `outside-match` / `parallel-invitation` | 当前输入、实际位移、距离/速度/朝向、是否随后取消或改变 |
| `joint-exit` | 两位实际通过时刻、最终附着状态、最终构图、系统/主持协助 |

每帧继续保存 `actorDriver`（或现有 `bodySource` / `shadowSource`）、输入、门开度、占板者、双方状态、当前台词以及最终骨骼姿态。原片段门状态和当前门状态分开保存；回看不得用旧门状态覆盖现场。

在同一模拟帧内按“输入与角色运动 → 实时碰撞/占板/门 → 确认物理事实 → 状态与交接 → 记录”处理，避免一个事件同时按新旧控制对象各触发一次。暂停冻结动作与源游标，恢复后不重复触发。

## 四节点真实回看与课程分析

回看使用本局采样，不重新运行剧情。节点缺失、主持跳过或源段不足时，显示实际原因；不得用预录成功片段补成完整四段。正常完整流程提供四个节点，每个节点可包含相邻子段，卡片同时标出截取时间。

| 节点 | 先看的本局证据 | 可以讨论的课程概念 | 不能代替当事人下的结论 |
| --- | --- | --- | --- |
| 1. 我想出去，门却关了 | 首次占板、离板、门关闭、身体到门前 | 具身性：移动距离、速度和空间约束怎样改变行动 | 不能因试门次数判断能力或耐心 |
| 2. 影子还在脚下吗 | 分离、控制转移、身体穿回尝试、当前影子位置变化 | 审美距离：亲自操作与观看角色自行动作如何交替；具身性：接近不等于仍由同一输入控制 | 静止不是接受；远离不是拒绝关系 |
| 3. 同一步怎样改变后果 | 原源段与本次引用对应；当前影子在其间做了什么；接力顺序怎样形成 | 反身性：旁白、创作者和玩家对“正常动作/正确先后”的预设怎样被现场事实修正 | 不能宣称玩家一定认出了旧动作；需本人说明 |
| 4. 走出去以后怎样同行 | 侧方选位、身体实际接近或离开、是否匹配、最终两位离场 | 审美距离与具身性；投射：由本人解释对并行/重合画面的联想 | 不把结局归类为人格、依恋类型或疗愈结果 |

每段先播放画面，再可叠加输入和动作来源，最后提出问题。可以报告“提示出现后，下一段身体沿出口方向移动”“玩家影子实际先占了内板”；不能写“服从指导”“故意抵抗”或把先后顺序解读为心理动机。

完整课堂表达至少包含一项具体经验、一项准确概念、可核对分析和清楚表达。技术规模不计作分析深度。本体、四片段回看与讨论需共同纳入课程最多 15 分钟的总安排。

## 时长核算：不重复计算并行动作

下表是未实测的制作预算，按互不重叠的墙钟阶段计。自由移动、角色反应、读取一句台词可以同时发生；不能将三者相加。引用准备时的影子探索已计在准备/引用阶段；跨门时的留板反应已计在接力阶段。

| 互斥阶段 | 初步首玩预算 | 说明 |
| --- | --- | --- |
| 开场至首次实际试门失败 | 20–40 秒 | 包括实际发现踏板；熟悉玩家可能更短 |
| 分离、自主反应、交接 | 3–5 秒 | 主要无直接控制段，不能串成更长观看 |
| 身体“穿回”尝试 | 5–12 秒 | 玩家同时控制影子；只有一次尝试，不反复追逐 |
| 引用准备、真实引用、恢复现场 | 7–14 秒 | 源段通常 3–6 秒；长停留尾段单独标注 |
| 门边实时接力到双方外侧 | 15–30 秒 | 包括外板发现、撤脚恢复与换控；无重复留门任务 |
| 侧方选位、当前同行到双方离场 | 12–25 秒 | 包括匹配或并行；不强制先走完侧方路线 |
| 落幕与迟到片名 | 5–7 秒 | 只在两位均实际离场后开始 |
| **相加范围** | **67–133 秒** | 只是明确动作的预算，不能称为首玩实测分布 |

玩家额外观察、试探、折返和失误可能将首玩延长到 2.5–3 分钟，也可能没有这些行为。**本案新增三场带来真实差异，但单凭文字不能保证教师本体达到 150–180 秒，尤其不能把每条互斥分支和全部可选试探累加。**

首轮原型需记录主动操作、无直接控制、无输入、提示后停留、源段准备/引用与回看各自时间。若大多数真实首玩仍明显短于目标，应承认内容仍不足，继续设计一个有独立行动后果的新场面；不能增加身体追逐次数、旧动作播放遍数、步数任务、隐藏减速或字幕等待。不要把回看时长算成教师本体时长。

## 现有动画足以表达的范围

当前 `ANIMATIONS` 已有 `idle`、`walk`、`chase`、`look`、`shrug`、`sit`、`rise`、`bow`、`turn`、`struggle`、`surprise`、`reach`、`pivot_left`、`pivot_right`。本文只依赖 `idle` / `walk` / `look` / `surprise` / `reach` / `shrug` / 转身以及现有头胸目光叠加。

- “穿回”由走到脚部位置、低头、试走和回看表达；不需要穿衣、抓影子或新的手指动画。
- “邀请”由看向、短 `reach` 和后退半步表达；不声称现有 clip 能准确做招手、握手或牵手。
- “独立位置”由角色真实侧移和转身表达；不需要新增镜面、物件、舞伴或新场景。
- 影子与身体不新增相互实体碰撞，避免站位反应污染真实源路线。两者重合需要视觉匹配条件，门和墙碰撞仍各自生效。

## 必须揭露的设计风险与验收

1. 第一场很容易被演成角色追着玩家跑的重复片段。固定第一次看到的位置，只作一次尝试，后续改成目光和行动关系；不以追逐凑秒数。
2. 历史片段可能过短、缺乏个人特征，玩家未必认出。正确回看能证明来源，不能证明现场辨识感已经成立。
3. 影子踩内板导致身体先过是确实不同的分支，但会让角色主动完成外板发现；必须保留可见的看门、看同类外板和走过去，不能隔空开门。
4. 并行和重合不能做成隐形二选一测试。玩家方向随时有效；姿态匹配失败不惩罚，也不能因无输入自行结算。
5. 外庭过短时，影子会来不及从侧方赶到出口。必须调整真实空间或角色侧移路径，不能瞬移、透明墙或暗改身体速度。
6. 测试覆盖：首次教师游玩、不先玩学生版；早踩内板；引用前已在外板；引用时停在门洞；长时间首次压板；第一次上板即离板；历史尾段/跳过；交接持续按键；过门撤脚与返回；外庭直奔出口；接近后又离开；整场无输入；暂停/恢复；主持跳段；低帧率与手机摇杆。
7. 每条正常成功路径都应有真实四节点。主持跳段允许节点缺失，但回看必须解释缺失；不可用合成行为冒充玩家完成。

本文确认了可实施因果、触发与记录条款。新剧情的清晰度、趣味、时长和概念体验仍须通过真实首次试玩判断。
