# Demo 验证记录

2026-10-27。本文件记录工程检查和一次工具操作试玩，不把这些结果当成人类体验评价。

## 自动检查

- TypeScript 类型检查通过。
- 12 个 Node 测试通过：开场身体/投影同步、两个版本无操作自然结束、失焦暂停、旧路线原时序重演、教师版真实路线倒放、花盆碰撞/绕行、持续偏离仍落幕、主持人跳段来源、回看不改写记录、关节旋转/缩放插值、缺失事件不造卡、Float32 姿态 gzip 往返。
- Vite 生产构建通过。发布资源约 1.55 MB（未计网络 gzip 收益），包括约 0.51 MB 角色和约 0.27 MB 本地字体。
- 构建输出字体路径为相对路径，可用于 GitHub Pages 子目录。Three.js 主 JS chunk 大于 Vite 默认 500 kB 提醒阈值；整站资源仍低于初定 10 MB 预算。

## 浏览器交互

在 Codex 内置浏览器实际检查：

- 首屏、个人/教师切换、方向键移动和自然投影。
- 一次完整教师版：约 170.52 秒，实际输入留下一段路线，经历 arrival、return、echo、follow、reverse、rejoin，最终自然静止落幕；未使用系统代演。
- 该局导出记录有 5,117 帧，逐帧均有两套 22 关节 × 10 值（位移、四元数、缩放）的最终姿态；所有姿态值有限。
- 实际回看四个节点、时间轴跳转、打开控制来源与轨迹层、「旁白，改口」及下载记录。
- 首次完整记录以未压缩 JSON 验证，约 36 MB。其后增加 Float32 内存存储与浏览器 gzip 导出；压缩往返有自动测试。另实际下载提前结束的个人短局：142 帧、61,440 字节 gzip，逐帧均有两套完整姿态，解压后所有值有限，包含手动落幕的最后一帧。
- 390 × 844 CSS 像素的 iframe 视口检查个人版布局、方向盘拖动和松手复位。这是窄屏浏览器验证，不是实体手机性能测试。
- 检查时浏览器控制台没有 warning/error。

## 验证边界

- 尚未做实体 iPhone/Android、教室投影或多浏览器硬件性能矩阵；不能承诺所有手机稳定 30 fps。
- 未开展不知情参与者测试；“能否认出自己的动作”“旁观是否有趣”仍需实际试玩。
- 回看是状态重绘，不是录屏，不承诺不同 GPU 逐像素一致。
- 导出用于留存和外部分析；当前页面没有导入功能。刷新前请按需保存。
- 记录未上传到服务器或源码仓库。仓库只保留验证摘要和不含真实参与者的资产检查图。

线上部署状态由 GitHub Actions 和实际线上页面分别核对，不用本地 build 成功代替发布完成。
