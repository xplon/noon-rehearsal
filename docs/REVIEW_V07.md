# v0.7 独立评审与修复

2026-11-05。实现初稿后启动三位全新上下文的评审。故事评审、旁白与状态评审只收到冻结源码和运行摘要；第三位另外收到匿名 A/B 实现做比较。没有提供用户批评、设计规格或期待结论。它们独立读实现、用正常输入复现，没有真人参与，也没有浏览器视觉审查。根代理另做实际浏览器检查。

## 评审结论

三位没有给出“已经证明好玩”的结论。初审共同指出：故事比旧版集中，但角色发展有一部分只有台词、缺少实际动作。最终定向复核认为已确认的状态与台词反例得到修复，教师倒序有了明确的喜剧起因和结果；适合定位为短篇互动表演。模型评审不能证明真实玩家的趣味、理解或教学效果。

## 发现与处理

| 独立发现 | 最终处理与证据 |
| --- | --- |
| 身体已在终点，“我来带路”一帧即完成 | 依据身体当前位置选择较远的门侧位置；常规带路约 3.02 秒、2.49 场景单位；预先等在两点及中点的反例也实际移动。玩家不跟随时不记完成。 |
| 影子先跨门又退回，身体未过门仍记共同通过 | 两位都越过实际门槛、接近并停稳才成功；退回反例不再产生成功。 |
| 陪坐时影子以坐姿移动 | 移动或呼叫打断先起身，再允许移动；不再宣称分离后仍坐在一起。 |
| 门口朝搭档移动被锁成先走，呼叫按钮失效 | 仅朝门外的输入尝试先走；跨门前可反悔或呼叫，走回搭档也有效。 |
| 拒绝后仍播放失效邀请 | 撤销待播过门邀请；保持当前已显示台词的阅读区间。 |
| 结果结算后又接收迟到成功 | 结算期间身体停步等转场，记忆、结果与台词不再被另一结果覆盖。 |
| 自动等候被说成玩家喊话；未留门却被结尾称留过 | 使用能由记录支持的会合、回望描述，删除不成立的归因。 |
| 同一越门事件每帧重复记录 | 单次成功只记一次。 |
| 零路线先说不重来，随后又说走完 | 零路线独立收束，不伪造倒序经历。 |
| 追加一段只有自由走动 | 增加影子先鞠躬、身体惊讶后回应；接受动作后先刹停，截止不打断已接受的谢幕。 |
| 自动谢幕提前截断邀请 | 自动停步触发需读完台词；明确按按钮可直接开始。 |
| 回看将真实观察划掉，却纠正不存在的心理推断 | 原话保留；按钮改为说明导演和程序的安排，补充记录随导出保留。 |

第二轮新增的鞠躬滑行、截止前点击、固定领路终点反例也经过定向复核。谢幕权重 >0.8 时最大速度约 0.00622，根位移约 0.000761 场景单位；第 28、29、29.9 秒接受谢幕均完成并只产生对应结果。这个数值检查不等于严格足底 IK。

## 趣味性、时长与仍有的限制

- 前面的先走或会合，会改变后续是身体寻找搭档，还是身体主动领路；先走后留门前多一次定位和确认。过去的选择影响实际状态与动作，并非只有结尾换一句话。
- 教师倒序现在围绕“一人名单、两位演员”展开：导演想倒回去排成一位，倒回后仍是两位，承认改名单并交出结尾。它仍是预设段落，不能声称玩家改变了导演的倒序安排。
- 大部分路径仍会汇合，双人谢幕也是一个固定的小场面，复玩内容量有限。结尾邀请、恢复控制与真正离场是不同环节，仍可能被部分玩家感觉为多次收尾。
- 正常 follow 的字幕覆盖率从初稿约 99.9%降至修订中约 89–90%，但仍偏密。后续应以真人是否在读字幕时错过动作来判断，不能只用覆盖率衡量艺术质量。
- 根据长路径审查，最终将开场旧路线重演上限从 30 秒缩短为 16 秒；仍保留前 6 秒观察窗和本人的真实动作。它减少重复，不增加填时。
- 自动策略中，快速个人路线 74–94 秒，教师 105–126 秒；实际教师局 133.28 秒。**没有把两分钟设成最低时长，也没有证明新玩家的平均时长。** 空闲与探索路径见验证表。

可行性：实现复用现有骨骼、门、动画与录制系统，没有新增运行时模型服务或后端。53 项回归、实际两版游玩、横屏和原话回看支持工程可运行性。课程的 15 分钟约束针对整个报告，没有规定游戏必须恰好两分钟；课堂预算应给真实体验、四段回看和概念分析留时间。
