# 正午排练场 · Noon Rehearsal

一处正午庭院、一名演员、一项普通的小任务。一个采用 3D 场景、骨骼动画与 3 渲 2 画面的浏览器互动短剧。

首次体验的说明保持简短。建议先玩完，再阅读技术与创作说明。

[在线入场](https://xplon.github.io/noon-rehearsal/)

## 运行

```sh
npm ci
npm run dev
```

打开终端显示的本地地址。生产构建：`npm run build`；本地预览构建：`npm run preview`。

- 电脑：方向键 / WASD。
- 手机：横屏游玩，右侧拖动方向盘；竖屏显示转屏提示，演出中转回竖屏会自动暂停。静音也可完整游玩。
- 个人体验约 2 分钟，剧场演出约 3 分钟；实际时长随路线和操作变化。
- 两版都有暂停与提前落幕；教师版另有跳段控制。失焦会暂停，返回后点继续。
- 个人版完整落幕、揭题后结束，不设回看；教师版结束后可回看本局片段与动作来源。

## 本局记录

角色动作、输入与事件只存在当前页面内存。没有游戏后台、用户账号或遥测上传。教师版可主动导出 JSON 记录（支持的浏览器自动 gzip 压缩）；刷新或关闭页面会清除未导出的记录。回看使用本局采样的角色状态与最终骨骼姿态，不重新运行剧情判断；它不是屏幕录像。当前 demo 的导出用于留存与外部分析，尚未提供记录导入界面。

## 实现与资产

- Three.js + TypeScript + Vite；固定正交镜头，定制色阶、结构线、整个人物的屏幕空间描边、原角色网格投影。
- KayKit Hooded Rogue（Kay Lousberg，CC0）改编角色：约 4.5 头身，保留原动作节奏并重新匹配较长的四肢；42 根骨骼、12 段动作、约 0.63 MB GLB。保留来源、许可、可编辑 `.blend`、改编脚本与检查图。
- 庭院为可编辑的程序化三维场景；背景、模型与声音均无运行时外部素材请求。上方字幕与舞台分区，镜头按建筑实际边界完整取景。
- Noto Serif SC / Noto Sans SC 本地字体子集，许可证随字体分发。
- 60 Hz 逻辑、30 Hz 状态与最终关节变换采样；回看的位置与旋转插值。
- 连续速度、受限加速度与转向、按实际位移推进步态、圆圈轻吸附；跟随结束先会合，再恢复正常投影。
- 影子有察觉、试着跟上又收住的反应；身体先观察再追随，急转方向会回头确认。门、叶片与旗帜按游戏时间轻动；声音开启时门会偶尔轻响。
- 所有关键阶段都有非配合/无操作的继续路径；系统代演、归位和主持人跳过有来源记录。

## 验证与发布

```sh
npm run check
npm test
npm run build
```

GitHub Actions 构建并发布 `dist/` 到 GitHub Pages。字体和模型均使用相对生产路径，支持项目子目录部署。

这是一份可继续打磨的艺术课程 demo。程序检查验证机制与数据一致性；艺术感受、能否认出自己的动作、课堂投影可读性仍需要真实试玩和现场确认。
